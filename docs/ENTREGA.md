## Texto de entrega

Presento **KelseTS Talks**, una aplicación full stack de gestión de eventos desarrollada con React, Node.js, Express y MongoDB Atlas. Incluye autenticación JWT, creación y edición de eventos, subida de imágenes a Cloudinary y gestión de asistencia con referencias entre usuarios y eventos. La interfaz está disponible en español e inglés.

Frontend y backend se organizan en carpetas independientes dentro del mismo repositorio. Las variables de entorno necesarias para la corrección se facilitarán por el canal privado de entrega, separadas del repositorio público.

Los ponentes, eventos y asistentes de demostración son ficticios y tienen finalidad académica. El correo se verifica en Mailtrap Sandbox; no se presenta como entrega a buzones reales.
