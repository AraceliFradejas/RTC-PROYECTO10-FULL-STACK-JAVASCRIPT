# Invitaciones de los ponentes

Ocho invitaciones ES/EN aprobadas en `frontend/public/videos/speakers/`, usadas por `speakerVideos.json`.

Estas carpetas conservan los retratos y audios fuente aprobados, guiones y parámetros de las voces. Los audios finales se nombran `*-approved.mp3`; las pruebas descartadas se han eliminado.
